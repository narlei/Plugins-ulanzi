Polling
More Information
The polling rate defines how often a new measurement value should be retrieved (heartbeat).

The actual display speed (FPS) depends on the specific monitoring method and how quickly the data can be read.

However, the actual sampling may take longer if the measurement function itself requires more time than the polling interval.

As a result, the effective acquisition rate may be lower than the configured polling rate.

The polling rate in Libre Hardware Monitor depends on the sampling interval and cannot exceed it.

Max Value
More Information
The MAX setup defines the reference point for the chart line percentage calculation.

The values always need to be adjusted when setting custom LHM options, since, for example, the temperature range typically requires completely different maximum values than the fan speed.

MIN is currently set to 0 by default. If a percentage value is being read, the MAX sliders should be set to MAX=100.

More Information
MIN/MAX setup is not available for this selection:

─ Percentage values are normalized with
a minimum of 0 and a maximum of 100

─ For some system monitor values, the maximum is automatically determined based on the detected hardware.

More Information
If Enabled, the currently measured values is written in a log file under C:\Temp\SV_***.log

If the file reaches a size of 10 MB, it is saved as a backup in the same path away.

The log file may not be open or blocked exclusively from other programs while the Stream Deck writes.

Optimal to open the log file is Notepad++

PRIVACY PROTECTION
YOUR PRIVACY MATTERS
We do not collect or store any private, personal, or sensitive data. The telemetry mechanism is limited to anonymous, technical usage statistics.

Show More
TELEMETRY DETAILS
When the software is launched for the first time, it creates a random, anonymous identifier (UUID as defined in RFC 4122). This identifier is used solely to send a one-time status ping during startup and to gain basic insights into how the software is used. It contains no personal or device-related information, is not linked to IP addresses or any other data source, and is never shared with third parties.

GDPR COMPLIANCE
The UUID does not qualify as personal data under Article 4(1) of the GDPR. Since re-identification is technically excluded, no consent under Article 6(1)(a) is required. This implementation fully adheres to the GDPR principle of data minimization (Article 5(1)(c)).
